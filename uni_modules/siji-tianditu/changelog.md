# 更新日志

## 1.0.3（2026-06-16）

### 新增功能
- ✅ **搜索交互优化**
  - 新增"取消"按钮，点击搜索框或有搜索内容时显示
  - 点击"取消"按钮清空搜索并恢复附近地点列表
  - 清除按钮（×）仅在有搜索内容时显示

### 搜索优化
- ⚡ **搜索结果优化**
  - 搜索结果数量从10条增加到50条
  - 客户端按距离排序，优先显示附近结果
  - 同时支持全国范围搜索，不会遗漏远处地点
  - 解决了搜索关键词时近处结果被忽略的问题

## 1.0.2（2026-06-13）

### 新增功能 搜索

#### 地图选择器增强
- ✅ **全国范围搜索**
  - 新增搜索框，支持关键词搜索地点
  - 支持全国范围搜索（queryType: 1），不受当前位置限制
  - 可在杭州搜索襄阳的"古隆中"等跨区域地点
  
- ✅ **智能关键词提取**
  - 拖动地图时自动提取逆地理编码结果中的POI作为搜索关键词
  - 自动搜索并显示附近地点，提升用户体验
  
- ✅ **距离计算与排序**
  - 所有搜索结果自动计算与当前位置的距离
  - 搜索结果和附近地点均按距离从近到远排序
  - 距离格式化显示（如：500m、1.2km）
  
- ✅ **交互优化**
  - 拖动地图时自动清空搜索关键词并搜索附近地点
  - 点击列表中的地址时不触发搜索，避免重复请求
  - 搜索框支持清空按钮
  - 每次打开地图时自动清空上次的搜索关键词

- ✅ **UI优化**
  - 顶部新增"取消"和"完成"按钮，水平布局
  - 地址列表显示优化，统一显示距离和地址
  - 当前位置与搜索结果格式统一

#### 新增工具函数
- ✅ `searchPlace(keyword, mapKey, options)` - 全国范围地点搜索
- ✅ `searchNearby(lon, lat, mapKey, options)` - 周边POI搜索
- ✅ `getDistance(lon1, lat1, lon2, lat2)` - 计算两点距离

### 优化改进
- ⚡ 搜索性能优化，使用防抖减少API调用
- 🎯 返回数据优化，`formatted_address` 返回完整地址而非名称
- 🔧 过滤重复POI，避免当前位置与搜索结果重复显示

## 1.0.0（2026-06-06）

### 首次发布

#### 核心功能
- ✅ 基础地图组件 `siji-tianditu`
  - 支持地图显示和交互
  - 支持自定义中心点和缩放级别
  - 支持中心定位图标显示
  - 支持定位按钮
  - 支持地图拖拽事件
  - 支持地图加载完成回调

- ✅ 地图选择器组件 `siji-tianditu-picker`
  - **弹窗选择模式**：显示地图界面，支持手动选择位置
    - 自动定位功能（每次打开自动定位到当前位置）
    - 实时地址解析（拖拽地图自动获取地址）
    - 完整的交互流程（确认/取消按钮）
    - 位置信息展示（经纬度、地址）
  - **直接获取模式**：无需显示地图，直接获取当前位置
    - 新增 `getLocationDirectly()` 方法
    - 自动获取设备当前位置
    - 自动进行逆地理编码
    - 返回完整的位置和地址信息
    - 内置加载提示和错误处理
    - 支持 Promise/async-await 语法

#### 工具函数
- `getAddressByLocation` - 逆地理编码（坐标转地址）
- `getLocationByAddress` - 正地理编码（地址转坐标）

#### 代码优化
- 提取公共方法，减少代码重复
  - 新增 `_getCurrentLocation()` 通用定位方法
  - 新增 `_getLocationWithAddress()` 组合定位和逆地理编码
  - 代码量减少约 30%
- 使用 async/await 替代回调嵌套
  - 提升代码可读性
  - 更好的错误处理
- 智能错误提示
  - 根据错误类型显示不同提示信息
  - 区分定位失败和地址获取失败

#### 特性
- 移除硬编码 API Key，提升安全性
- 支持 H5、App（Android/iOS）
- 现代化 UI 设计
- 组件化封装，易于使用
- 自动地址解析
- WGS84 坐标系
- 两种使用模式：弹窗选择 / 直接获取

#### 技术栈
- uni-app 框架
- Vue.js
- 天地图 API v4.0
- RenderJS（用于 H5 端地图渲染）
